Privacy policy

Last updated 28 October 2026.

What the app is

The Kenya on Record publishing tool is a private application used only by the owner of the Kenya on Record channel. It uploads the channel's own videos to the channel's own YouTube account. It is not offered to the public and has no other users.

What it accesses

It asks for one Google permission: uploading videos to the owner's YouTube channel. It does not read the owner's email, contacts, files or private YouTube data.

What it stores

The owner's authorisation token is kept in the project's private secrets store. It is not shared with anyone, sold, or used for advertising. We do not collect personal data from visitors or viewers.

Google API data

Use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.
